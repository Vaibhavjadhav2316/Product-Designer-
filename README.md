# Product Designer Portfolio

A single-page portfolio website inspired by **Cynthia Ugwu's portfolio**, built using HTML, CSS, and JavaScript. The website features a dark, typography-focused design with smooth scrolling, animated text, interactive project previews, and custom cursor effects.

## Features

- **Animated Hero Section** — Introduction, designer details, and availability.
- **Interactive Project Gallery** — Featured projects with hover-based image previews and rotation effects.
- **About Section** — Designer biography and profile image.
- **Custom Cursor** — Cursor movement effects for a more interactive experience.
- **Smooth Scrolling** — Smooth page navigation using Locomotive Scroll.
- **GSAP Animations** — Animated page elements and transitions.
- **Contact and Social Links** — Sections for contact, subscription, and social profiles.

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling, layout, and visual effects |
| JavaScript | Interactions and functionality |
| GSAP | Animations and transitions |
| Locomotive Scroll | Smooth scrolling |
| Remix Icon | Icons |

GSAP, Locomotive Scroll, and Remix Icon are loaded through CDNs. An internet connection is required for these external resources.

## Getting Started

### Prerequisites

- A modern web browser.
- An internet connection for external libraries loaded through CDNs.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Vaibhavjadhav2316/Product-Designer-.git
   ```

2. Open the project folder:

   ```bash
   cd Product-Designer-
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in VS Code for local development.

No package installation or build step is required.

## Customization

- Update the content and image references in `index.html`.
- Modify the layout, colors, typography, and effects in `style.css`.
- Customize cursor behavior, scrolling, and animations in `script.js`.
- Replace placeholder contact and social links with your own destinations where appropriate.
